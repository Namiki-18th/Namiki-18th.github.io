プライバシーポリシー

最終更新日：2024年8月15日

1. はじめに

本ダッシュボール（以下、「本サービス」）は、ユーザーの個人情報を大切に取り扱います。 本プライバシーポリシーは、本サービスにおいて、どのような個人情報を収集し、 どのように利用・管理するかについて説明するものです。

2. 収集する情報

本サービスは、以下の情報を収集することがあります。

2.1 ユーザーが提供する情報

  • Googleアカウント経由で提供される情報（メールアドレス、名前、プロフィール画像）
  • ダッシュボード上で入力される情報（任意入力項目）

2.2 自動的に収集される情報

  • アクセスログ（IPアドレス、アクセス日時、ブラウザ情報）
  • セッション情報（クッキー、セッションID）
  • デバイス情報（OS、ブラウザ種別）

3. 情報の利用目的

本サービスは、収集した個人情報を以下の目的で利用します：

  • ✓ ユーザー認証とセッション管理
  • ✓ サービスの提供と改善
  • ✓ セキュリティの維持・向上
  • ✓ 不正利用の防止
  • ✓ ユーザーサポート対応
  • ✓ アクセス統計の分析（個人識別できない形式で）

4. 情報の管理

4.1 セキュリティ対策

本サービスは、個人情報の紛失、破壊、改ざん、および不正アクセスを防止するために、 以下のセキュリティ対策を実施しています：

  • ✓ HTTPS（SSL/TLS暗号化通信）の使用
  • ✓ HTTPOnly Cookieによるセッション保護
  • ✓ 環境変数の秘密化
  • ✓ 定期的なシステムアップデート

4.2 データの保持期間

セッションデータはユーザーのログアウト時または24時間後に自動削除されます。 統計データは個人識別できない形式で保持可能です。

5. Google OAuthについて

重要： 本サービスは Google OAuth 2.0 を使用して認証を行っています。

  • Googleに送信される情報は Google の プライバシーポリシー に従って管理されます
  • 本サービスは、Googleから取得したアクセストークンを安全に管理します
  • Googleアカウントの詳細情報（メール、パスワード等）は本サービスに保存されません

6. 第三者への情報提供

本サービスは、ユーザーの同意なく個人情報を第三者に提供することはありません。 ただし、以下の場合は例外とします：

  • 法令に基づく場合
  • 個人の生命、身体または財産の保護のため必要な場合
  • 公衆衛生の向上または児童の健全な育成の推進のため

7. クッキーの使用

本サービスは、セッション管理とユーザー認証のためにクッキーを使用しています。 これらのクッキーは以下の特性を持ちます：

  • セッション専用（ブラウザ閉鎖時に削除）
  • HTTPOnly属性で保護（JavaScriptからのアクセス不可）
  • 個人を特定する情報は含まない

8. ユーザーの権利

ユーザーは以下の権利を有しています：

  • ✓ 個人情報へのアクセス権
  • ✓ 個人情報の修正・削除請求権
  • ✓ 個人情報処理の停止請求権
  • ✓ 任意の時点でのログアウト権

9. プライバシーポリシーの変更

本プライバシーポリシーは、予告なく変更される可能性があります。 変更がある場合は、本ページにおいて「最終更新日」を更新します。

10. お問い合わせ

本プライバシーポリシーまたは個人情報の取り扱いについてご質問がある場合は、 以下の連絡先までお問い合わせください：

学校生活ダッシュボール 管理者
メール: support@namiki-cs.ibk.ed.jp

※ 本フォームは技術的なお問い合わせにのみ対応しています

11. 法的根拠

本プライバシーポリシーは、以下に基づいています：

  • 個人情報の保護に関する法律（APPI）
  • 一般データ保護規則（GDPR）
  • Google API に関するポリシー
  • Renderのプライバシーポリシー

12. 補足事項

本ダッシュボールはデモンストレーション・教育目的で提供されています。 本番環境での使用を検討する場合は、適切なセキュリティ監査を実施してください。
