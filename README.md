## Google 審査チームの皆様へ

本ドキュメントは、茨城県つくば市（〒305-0044 茨城県つくば市並木4丁目5-1）に位置する公立中等教育学校である**茨城県立並木中等教育学校**の、特定学年（18回生）の卒業生のために構築された招待制プライベートコミュニティポータル「**並木中等教育学校18回生**」について説明するものです。本サービスは卒業生（Taichi Kimura）によって独立して運営されているものであり、**学校の公式システムではありません**。

本アプリケーションは、メンバーのGoogleアカウントに対する本人確認および対象学年の正当な構成員（および管理者1名）へのアクセス制限のみを目的として **Google OAuth 2.0 / OpenID Connect** を使用しています。ログインユーザーの特定に必要な基本的な **`openid`, `email`, `profile`** スコープのみを要求しており、機密性の高いスコープや制限付きスコープは一切要求していません。

公開トラフィックはすべて **Cloudflare**（DNS、CDN、TLS終端、エッジ/WAF保護）を経由して静的ランディングページ（GitHub Pages）またはアプリケーションサーバーに配信されます。技術仕様書（アーキテクチャ図、ソースコード構造、画面遷移図）の詳細は OAuth 検証申請時に**補足ZIP添付ファイル**として提出済みです。本ページは匿名訪問者および審査員向けの公開概要です。データ取り扱いおよび限定使用コンプライアンスの詳細は、下記の**セキュリティ & データ保護方針**に記載しています。

## サービス概要

**並木中等教育学校18回生** は、茨城県立並木中等教育学校のある学年（18回生）の卒業生・在校生コミュニティ専用に開発された、招待制のクローズドなWebポータルです。学年内の連絡事項・カレンダー・時間割・チャットなど、限定されたメンバー間の情報共有を目的としており、不特定多数への公開は行っていません。

対象ユーザーは、学校が発行するメールドメイン（`@namiki-cs.ibk.ed.jp`）を保有する当該学年の在校生・卒業生に限定されます。Googleアカウントでのログインを必須とすることで、なりすましや部外者のアクセスを防ぎ、学年内の情報共有という課題を安全に解決します。

## 主な機能

- **Google OAuth 2.0 統合認証**：学校ドメイン限定 + 管理者アカウント例外による安全なログイン
- **ダッシュボード & 情報共有**：お知らせ・時間割・Google Classroom連携情報など、ユーザー専用ページの閲覧
- **カレンダー共有**：学年行事・イベントの一覧表示
- **通知・リマインド機能**：更新情報のお知らせ配信
- **リアルタイムチャット**：学年全体 / クラス単位 / 個人間のメッセージ共有（暗号化保存）
- **管理者パネル**：権限管理・メンテナンスモード切り替えなど、限定された管理機能
- **交通運行情報**：通学に関わる公共交通機関のリアルタイム情報表示

## インフラ・システム構成

本サービスは、すべての通信を **Cloudflare（DNS / CDN / WAF / エッジセキュリティ / SSL・TLS終端）** を経由して配信しており、エンドユーザーとオリジンサーバーの間に多層的な防御層を設けています。公開ランディングページは **GitHub Pages** 上で静的ホスティングされ、アプリケーション本体は独立したアプリケーションサーバー上で稼働します。
