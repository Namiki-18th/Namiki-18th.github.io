プライバシーポリシー

本ポータルサイトにおける個人情報の取扱いおよびセキュリティ方針について規定しています。

「並木中等教育学校18回生ポータルサイト」（以下、「当サイト」といいます。）は、利用者のプライバシーを尊重し、個人情報の保護と適切な管理に努めます。

Google API サービスデータポリシーへの準拠

本アプリケーションおよびその開発者は、Google API サービスデータポリシー（Google API Services User Data Policy）、および該当する場合の限定使用要件（Limited Use Requirements）を遵守します。Google APIから取得したユーザーデータの利用は、本アプリがユーザーに提供する機能の実現に必要な範囲に厳格に限定されます。

1. 取得データと利用目的

当サイトでは、Google OAuth2 等の認証連携を利用してログインを行う際、以下の情報を自動的に取得します。上記以外の個人データをGoogle OAuth経由で取得することはありません。

取得データ スコープ 利用目的
Googleアカウント一意識別子 openid 本人確認・ログインセッションの管理
メールアドレス email 学校ドメインによるアクセス可否判定、本人特定
氏名・プロフィール画像 profile ダッシュボード・チャット等での表示名・アイコン表示

※当サイトが利用者のGoogleアカウント等のパスワードを取得・保存することは一切ありません。

2. 個人情報の利用目的

取得した個人情報は、以下の目的でのみ利用します。

  • 利用者認証および本人確認
  • 当サイトにおけるクラス・学年機能（お知らせ、時間割、チャット等）の提供
  • 不正アクセスや違反行為の防止および安全な運用管理

3. 通信の暗号化とデータ安全管理

当サイトは、利用者の個人情報およびメッセージデータを保護するため、以下の安全対策を導入しています。

  • 通信の暗号化（TLS 1.3/HTTPS）： クライアント・サーバー間のすべての通信は、Cloudflareが提供する HTTPS / TLS により暗号化されています。
  • 保管データの暗号化（AES-256）： サーバー内で保持する機密性の高い情報（名簿データやチャットメッセージ等）は、AES-256-GCM等の業界標準の暗号化方式により保護された状態で保存されます。
  • エッジセキュリティ防御： Cloudflareのエッジセキュリティ機能（WAF・DDoS防御・レートリミット等）により、不正アクセスや多重リクエスト攻撃からサービス基盤を保護しています。
  • ドメイン制限・アクセス制御（RBAC）： 特定の学校ドメインのGoogleアカウントのみのアクセスを許可し、他者のデータに不正アクセスできないよう厳格な認可制御（IDOR対策）を実施しています。
  • スクリプト・セッションの保護： CSP（Content Security Policy）によるXSS対策、SameSite属性によるCookie保護、およびタイミング攻撃対策を採用しています。

4. チャットデータの管理とアクセス制限

チャット機能で送信されたデータは暗号化して保存されます。原則として第三者に公開されることはありませんが、システムセキュリティの保持や不正行為調査等の正当な理由がある場合、管理者が適切かつ必要最小限の範囲で確認を行うことがあります。

5. 第三者提供・目的外利用の禁止

取得したユーザーデータの取り扱いについては、以下の原則を厳守します。

  • 取得したユーザーデータを第三者へ販売・提供することはありません。
  • 取得したユーザーデータを広告目的で利用・共有することはありません。
  • 取得したユーザーデータをAI／機械学習モデルの学習・トレーニングに使用することはありません。
  • データは本アプリが提供する機能（認証・表示・アクセス制御）以外の目的には使用しません。

6. データの保持・削除

ユーザーは、いつでも自身の登録データおよび連携アカウント情報の削除を求めることができます。

  • 連携解除: Googleの「アカウントにアクセスできるアプリ」画面より、当アプリへのアクセス権限を即座に取り消すことができます。
  • データ消去の申請: ユーザーは、お問い合わせ窓口（contact@namiki-18th.net または privacy@namiki-18th.net）よりアカウント削除・データ消去を申請できます。申請を受理した開発者は、本人確認の上、対象アカウントに紐づくデータをシステムから速やかに削除します。

7. プライバシーポリシーの改定

当サイトは、法令の改正や運用の変更に応じて、本プライバシーポリシーを適宜見直し、改定することがあります。改定後の内容は、当サイト上に掲載した時点より効力を生じるものとします。
